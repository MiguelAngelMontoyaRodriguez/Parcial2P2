# Parcial2P2
## SmartLibrary- Patrones de diseño en Java

##Pensamiento computacional
### Abstracción
Sistema de biblioteca digital que gestiona recursos académicos 
(libros, artículos, audiolibros), organizados en colecciones y 
subcolecciones, con control de acceso y funcionalidades opcionales.

### Descomposición
- Recursos individuales → RecursoSimple
- Agrupación de recursos → Coleccion
- Integración externa → AdaptadorRecurso
- Control de acceso → ProxyRecurso
- Funcionalidades opcionales → Decorators
- Construcción flexible → RecursoBuilder

### Reconocimiento de Patrones
| Necesidad | Patrón |
|---|---|
| Colecciones uniformes | Composite |
| Proveedor externo | Adapter |
| Acceso restringido | Proxy |
| Funcionalidades opcionales | Decorator |
| Construcción flexible | Builder |
